# 핵심 룰 v0.1 — 2v2 비밀 배치 라인전 (가칭)

작성일 2026-09-25. 종이 프로토타입으로 검증하기 위한 첫 룰셋. 숫자는 전부 임시값이며 플레이테스트로 조정한다.

## 1. 한 줄 요약

세 라인(탑·미드·봇)에 양 팀이 **동시에, 몰래** 유닛을 배치하고, 공개 뒤 라인별로 자동 전투가 벌어진다. 상대 타워 2개를 먼저 부수는 팀이 이긴다. 매 턴의 핵심 결정은 "뭘 살까"가 아니라 **"어디에, 언제, 얼마나 걸까"**다.

## 2. 구성

| 항목 | 값 |
|---|---|
| 인원 | 2v2 (기본), 1v1 (개인전, 같은 룰) |
| 라인 | 탑, 미드, 봇 |
| 타워 | 라인마다 팀별 1개, 체력 15 (1v1은 10) |
| 라인 슬롯 | 팀당 라인마다 최대 4유닛 (2v2에서는 두 팀원이 4칸을 **공유**) |
| 턴 수 | 7턴 |
| 마나 | 각 플레이어 매 턴 = 턴 번호 (1턴 1마나 … 7턴 7마나), 이월 없음 |
| 덱 | 플레이어당 20장, 시작 손패 3장, 매 턴 1장 드로우, 손패 최대 7장 |
| 승리 | 상대 타워 2개 파괴 시 즉시 승리. 7턴 종료 후엔 파괴한 타워 수 → 남은 타워 체력 합 → 미드 타워 체력 순으로 비교 |

## 3. 턴 진행

1. **턴 시작**: 마나 충전, 각자 1장 드로우. 2턴·5턴엔 개인 증강 선택(3장 중 1장). 3턴·5턴엔 라인 규칙 공개(6절).
2. **핑**: 각 플레이어는 팀원에게 핑 1개를 보낼 수 있다. `라인(탑/미드/봇) × 의도(간다/버려/도와줘)` 9종. 상대 팀은 못 본다. 채팅은 없다.
3. **비밀 배치**: 마나 안에서 손패의 유닛을 원하는 라인에 놓고 **확정**한다. 팀원이 이미 확정한 배치는 보이고, 확정 전 배치는 안 보인다. 상대 팀 배치는 공개 전까지 절대 안 보인다.
4. **공개**: 양 팀 배치가 동시에 공개된다. 라인 안 순서는 먼저 놓인 유닛이 앞(맨 앞 = 가장 오래된 유닛).
5. **전투 해결** (라인별, 동시 처리):
   - 각 유닛은 상대 라인의 **맨 앞 유닛**에 자기 공격력만큼 피해를 준다. 맨 앞이 죽으면 남은 피해는 다음 유닛으로 이월된다.
   - 상대 유닛이 없으면 상대 **타워**를 공격한다.
   - 피해는 전투 시작 시점 상태를 기준으로 양쪽이 동시에 계산된다. 체력 0 이하 유닛은 제거.
   - 이번 턴에 배치된 유닛도 이번 턴에 공격한다 (증강으로 바뀔 수 있음).
6. **턴 종료 효과** 처리 → 타워 파괴 확인 → 다음 턴.

배치된 유닛은 다른 라인으로 옮길 수 없다. 유닛은 죽을 때까지 라인에 남는다.

**구현하면서 확정한 세부 규칙** (엔진 `GameEngine.cs` 기준):
- 이월 피해는 유닛 사이에서만 넘어가고 **타워로는 넘어가지 않는다**. 전투 시작 시점에 상대 유닛이 하나라도 있으면 (화염 궁수를 제외한) 모든 공격이 유닛 줄에 쏟아지고, 남는 피해는 버려진다.
- 나무 수호자는 타워에 들어오는 **공격 하나당** 1씩 줄인다 (여러 마리면 중첩).
- 기습(증강)으로 보호된 유닛과 안개로 숨은 유닛은 공격 대상에서 빠진다. 그 라인에 그런 유닛만 있으면 상대는 타워를 친다. 마법사 시너지·용의 둥지 같은 광역 피해는 보호를 무시한다.
- 안개 라인에 배치된 유닛은 그 턴에 공격도, 피격도 없다. 다음 턴 시작 시 공개된다.
- 정글 드로우는 죽인 팀에서 **손패가 가장 적은 플레이어**가 받는다.
- 시너지 조건이 깨지면 보너스 체력도 즉시 사라지고, 그 때문에 체력 0 이하가 되면 죽는다.
- 미션 보상의 마나 +3은 **다음 턴**에 들어온다 (미션 판정이 턴 종료에 이뤄지므로).
- 배치 확정 순서는 팀0 P0 → P1 → 팀1 P0 → P1 이며, 같은 턴에 양 팀이 놓은 유닛은 모두 공개된 뒤 배치 효과(불의 정령 폭발 등)가 그 순서로 발동한다.

## 4. 유닛 (프로토타입 10종)

표기: **코스트 / 공격 / 체력**. 태그는 `계열 · 직업`. 각 플레이어 덱 = 10종 × 2장 = 20장 (v0.1에서는 덱 구성 없음).

| # | 이름 | 코/공/체 | 태그 | 효과 |
|---|---|---|---|---|
| 1 | 다람쥐 정찰병 | 1/1/1 | 숲·궁수 | 배치 시 1장 드로우 |
| 2 | 멧돼지 돌격병 | 2/3/2 | 숲·전사 | 없음 |
| 3 | 나무 수호자 | 4/2/7 | 숲·전사 | 이 라인의 아군 타워가 받는 피해 -1 |
| 4 | 불꽃 임프 | 1/2/1 | 불·마법사 | 죽을 때 상대 맨 앞 유닛에 1 피해 |
| 5 | 화염 궁수 | 3/3/2 | 불·궁수 | 항상 상대 **타워**를 공격한다 (유닛 무시) |
| 6 | 불의 정령 | 5/5/4 | 불·마법사 | 배치 시 이 라인의 모든 상대 유닛에 1 피해 |
| 7 | 태엽 병사 | 2/2/3 | 기계·전사 | 없음 |
| 8 | 톱니 궁수 | 3/2/4 | 기계·궁수 | 턴 종료마다 공격력 +1 |
| 9 | 수리 드론 | 2/0/3 | 기계·마법사 | 턴 종료마다 이 라인 아군 맨 앞 유닛 체력 +1 |
| 10 | 강철 거인 | 6/6/6 | 기계·전사 | 이 라인에 아군 기계가 2 이상이면 코스트 -2 |

## 5. 시너지 (조합)

**계열 시너지**는 세 라인 전체, **두 팀원 합산**으로 센다. 팀원과 조합을 맞추는 이유가 여기서 생긴다.

| 계열 | 3명 | 5명 |
|---|---|---|
| 숲 | 아군 타워 전체 체력 +3 (도달 시 1회) | 매 턴 시작 시 아군 타워 전체 체력 +1 |
| 불 | 아군 유닛 공격력 +1 | 상대 유닛이 죽을 때마다 그 라인 상대 타워에 1 피해 |
| 기계 | 기계 유닛 체력 +1 | 기계 유닛 코스트 -1 |

**직업 시너지**는 같은 라인 안에서만 센다 (2명 이상).

| 직업 | 같은 라인 2명 이상 |
|---|---|
| 전사 | 이 라인의 아군 전사 체력 +2 |
| 궁수 | 이 라인의 아군 궁수 공격력 +1 |
| 마법사 | 턴 종료 시 이 라인의 상대 유닛 전원 1 피해 |

시너지는 조건이 깨지면 즉시 사라진다 (타워 체력처럼 "1회" 표시된 것 제외).

## 6. 증강

### 6-1. 개인 증강 (2턴, 5턴, 3장 중 1장, 비공개)

| 이름 | 효과 |
|---|---|
| 풍요 | 매 턴 드로우 +1 |
| 과부하 | 매 턴 마나 +1, 아군 타워 전체 체력 -1 (즉시) |
| 탑 지킴이 | 탑 타워 체력 +5 |
| 후퇴 명령 | 턴당 1회, 내 유닛 하나를 손패로 되돌린다 (배치 단계) |
| 쌍둥이 | 다음에 배치하는 1코스트 유닛의 복사본이 같은 라인에 추가된다 |
| 정찰 | 매 턴 상대 한 명의 손패 1장이 공개된다 |
| 도박사 | 매 턴 시작 시 동전 던지기: 앞면이면 마나 +2, 뒷면이면 +0 |
| 결속 | 계열 시너지 임계값 -1 (3→2, 5→4) |
| 심리전 | 상대 팀의 핑이 보인다 |
| 기습 | 이번 턴에 배치한 내 유닛은 상대 유닛의 공격을 한 턴 받지 않는다 |

### 6-2. 라인 규칙 (3턴, 5턴, 공개, 무작위 라인 하나에 남은 경기 내내 적용)

| 이름 | 효과 |
|---|---|
| 늪 | 여기 배치된 유닛은 배치된 턴에 공격하지 않는다 |
| 협곡 | 이 라인의 슬롯이 4 → 2로 줄어든다 |
| 정글 | 이 라인에서 상대 유닛을 죽이면 1장 드로우 |
| 용의 둥지 | 턴 종료 시 이 라인 양쪽 유닛 전원 1 피해 |
| 안개 | 이 라인의 배치는 **다음 턴에** 공개된다 (1턴 지연, 전투도 그때) |
| 고지 | 이 라인의 타워는 한 턴에 최대 5 피해만 받는다 |
| 전령 | 이 라인의 타워를 파괴하면 즉시 승리 |

라인 규칙은 양 팀에 똑같이 적용된다. 공개된 순간부터 라인의 가치가 달라지는 것이 목적이다.

## 7. 히든 미션

경기 시작 시 각 플레이어가 1장을 비밀리에 받는다. **팀원도 모른다.** 달성 즉시 공개되고 보상: 그 턴 마나 +3, 아군 타워 전체 체력 +2.

| 이름 | 조건 |
|---|---|
| 미드 집중 | 미드 타워를 파괴한다 |
| 위장 | 3턴 연속 한 라인에만 배치한다 |
| 균형 | 한 턴에 세 라인 모두에 배치한다 |
| 절제 | 3턴 이후 어느 턴에 마나를 하나도 쓰지 않는다 |
| 순혈 | 한 라인에 같은 계열 아군 유닛 4명을 동시에 둔다 |
| 소모전 | 경기 중 죽은 유닛(양 팀 합산)이 28명 이상 |

의도: 상대의 "이상한 수"가 블러핑인지 미션인지 읽어야 하고, 내 미션 때문에 팀원과 어긋나는 순간이 생긴다.

## 8. 해금 (메타, 여러 판에 걸쳐)

조건은 게임 안에서 보이지 않는다. 달성하면 알림과 함께 풀에 추가된다. v0.1 예시 3개:

| 조건 | 보상 |
|---|---|
| 한 판에서 상대 타워 3개를 전부 파괴 | 새 유닛 1종 |
| 마나를 한 번도 남기지 않고 승리 | 새 증강 1종 |
| 핑을 한 번도 안 쓰고 2v2 승리 | 새 이모트 |

## 9. 개인전 (1v1)

같은 룰. 플레이어 한 명이 팀 자리를 혼자 쓴다. 라인 슬롯 4, 덱 20, 핑 없음. 타워 체력은 10 (혼자서는 15를 못 뚫는다). 계열 시너지는 혼자서 채운다.

## 10. 종이 프로토타입 준비물

- 인덱스카드 40장 (각 플레이어 덱 20장 × 2팀… 4명이면 80장). 카드에 코/공/체/태그/효과 기입.
- 라인 3개를 그린 종이, 타워 체력은 10면체 주사위 2개 또는 토큰.
- 마나 토큰, 증강 카드 10장, 라인 규칙 카드 7장, 미션 카드 6장.
- 비밀 배치는 카드를 **뒤집어** 놓고 동시에 공개. 팀원 확정 배치는 앞면으로 두고 상대 쪽에서만 안 보이게 가림막 사용.
- 4명이 안 모이면 2명이 1v1로 먼저 검증한다.

## 11. 첫 플레이테스트에서 답해야 할 질문

1. 비밀 배치가 실제로 "읽기"를 만들어내는가, 아니면 그냥 운처럼 느껴지는가?
2. 라인 슬롯 4칸 공유가 팀원과의 조율 재미를 주는가, 짜증을 주는가?
3. 7턴이 너무 긴가? 승부가 4~5턴에 이미 결정되는가?
4. 화염 궁수(타워 직행)와 전령(즉시 승리)이 게임을 부수는가?
5. 한 번도 선택되지 않은 증강, 한 번도 달성되지 않은 미션은 무엇인가?
6. 팀원의 확정 배치를 보여주는 것이 맞는가, 아니면 아예 숨기는 편이 더 재밌는가?

## 12. 구현 원칙 (코드 작성 전 합의)

- **전투는 완전 결정론**: 같은 (덱 시드, 배치 순서, 증강 선택) 입력이면 어떤 기기에서도 같은 결과. 리플레이, 비동기 대전, 치팅 검증이 전부 여기에 기댄다.
- 게임 룰 코드는 Unity 오브젝트와 분리된 순수 C# (MonoBehaviour 없음)으로 작성해 단위 테스트가 가능하게 한다.
- 유닛·증강·미션 데이터는 코드가 아니라 데이터 파일(ScriptableObject 또는 JSON)로 두어 밸런싱을 코드 수정 없이 한다.

## 13. 시뮬레이션 v0.1 관찰 (2026-09-25)

`Assets/Scripts/Core`의 순수 C# 엔진으로 매치업당 1000판을 돌린 결과는 [sim-latest.md](sim-latest.md)에 있다 (Unity 메뉴 `LaneBattle/Run Simulation` 또는 `dotnet`으로 재생성). 에이전트는 무작위와 단순 탐욕 휴리스틱뿐이라 **사람 플레이와 다르다**. 룰의 구조적 문제만 읽어야 한다.

| 관찰 | 수치 | 판단 |

| 탐욕이 무작위를 이김 | 62.8 : 36.9 | 룰에 "실력"이 존재함. 통과 |

| 1v1 은 너무 굼뜸 | 조기 종료 8%, 판당 파괴 타워 0.39 | 타워 15는 1인 마나로 못 뚫음. **→ 1v1 타워 체력 10으로 반영** (조기 종료 33%, 파괴 1.1개) |
