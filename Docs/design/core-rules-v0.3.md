# 핵심 룰 v0.3 — 공격 디펜스 (실시간)

작성일 2026-09-25. v0.2 의 라운드제를 버리고 원작(스타크래프트 유즈맵 "공격 디펜스")처럼 **실시간 동시 진행**으로 바꿨다. 기본 게임 방법은 원작을 그대로 따르고, 우리 재미 요소(뽑기, 시너지, 증강, 미션, 해금)를 그 위에 얹는다. 숫자는 전부 임시값.

## 1. 한 줄 요약

내 팀 라인에 **타워**를 지어 상대가 보낸 유닛과 기본 웨이브를 막으면서, 같은 시간에 골드로 **뽑은** 공격 유닛을 상대 라인으로 보낸다. 타워는 공격만 하고 맞지 않는다. 공격 유닛은 싸우지 않고 **살아남아서** 기지를 친다. 상대 기지 체력을 먼저 0으로 만들면 이긴다. 모든 것이 동시에, 멈추지 않고 진행된다.

v0.2에서 바뀐 것:
- 라운드·준비 단계·확정 없음. 짓기·뽑기·보내기를 **언제든** 한다.
- 방어 유닛 → **타워**. 체력 없음, 공격 유닛에게 맞지 않는다.
- 공격 유닛은 공격력이 없다. 체력·속도·특수 능력·누수 피해·인컴만 있다.
- 유닛이 타워에 막히지 않는다. 타워는 사거리로만 말한다.
- 기본 웨이브는 **시간표**대로 온다 (30초마다).

## 2. 구성

| 항목 | 1v1 | 2v2 | 3v3 |
|---|---|---|---|
| 팀당 라인 | 1 | 1 | 1 |
| 타워 슬롯 (팀 공유) | 12 (4열 × 3줄) | 18 (6열 × 3줄) | 24 (8열 × 3줄) |
| 기지 체력 (팀 공유) | 30 | 45 | 60 |
| 기본 웨이브 규모 | ×1 | ×1.6 | ×2.2 |
| 경기 시간 | 10분 | 10분 | 10분 |

- **라인**: 상대가 보낸 유닛과 기본 웨이브가 라인 입구에서 나타나 내 기지까지 걸어온다. 라인 너비만큼 열이 있고, 유닛은 열 하나를 골라 직진한다. 타워 슬롯 격자가 라인 중간에 있다.
- **타워 슬롯**: 3줄 × N열. 타워는 사거리 안의 유닛을 자동으로 공격한다. 가운데 열 타워가 더 많은 유닛을 커버하고, 가장자리 열은 그 열만 본다. 자리 선택이 곧 계획이다.
- **기지 체력**: 유닛이 기지에 도달하면 **누수 피해**만큼 깎인다. 팀이 공유한다.

## 3. 자원

| 항목 | 값 |
|---|---|
| 시작 골드 | 플레이어당 40 |
| 골드 | **개인** 지갑 |
| 팀 인컴 | **팀 공유**. 팀원 누가 보내든 그 유닛의 인컴 값만큼 영구 증가. 시작값 = 8 × 팀 인원 |
| 수입 지급 | **10초마다** `팀 인컴 ÷ 팀 인원`을 각자 받는다 |
| 처치 보상 | 내 라인에서 죽은 유닛 1마리당 1골드, 팀 균등 분배 (나머지는 막타 순) |
| 팀원 송금 | 언제든, 제한 없음 |
| 공개 여부 | 인컴과 상대 타워는 공개, 골드 잔액과 손패는 비공개 |

공격이 곧 경제다. 보내지 않으면 팀 수입이 8×인원에 묶이고, 보내면 상대를 압박하면서 수입이 오른다. 타워에만 쓰면 안전하지만 가난하고, 보내기만 하면 부자지만 뚫린다.

## 4. 진행 (실시간)

경기는 10분간 멈추지 않는다. 각 플레이어는 언제든 아래를 한다.

- **타워 짓기**: 빈 슬롯을 골라 타워를 세운다. 골드 지불, **건설 2초** 후 작동. 짓는 동안은 공격하지 않는다.
- **강화**: 타워 1회 강화 (원가 지불, 공격·공속 +50%). 즉시.
- **판매**: 80% 환불, 즉시. 급할 때 자리 바꾸기용.
- **뽑기**: 5골드 → 공격 유닛 카드 1장이 손패에 들어온다 (7절). 손패 최대 6장.
- **보내기**: 손패의 카드를 골라 보낸다. 보내기 비용을 내고 팀 인컴이 오른다. 유닛은 **즉시** 상대 라인 입구에 나타나 걷기 시작한다. 여러 장을 연달아 보내면 무리가 된다.
- **송금 / 핑**: 팀원에게 골드, 또는 핑 (`막아줘 / 보낼게 / 아껴 / 공중 조심`).

시간표로 오는 것:

| 시각 | 일 |
|---|---|
| 0:30 부터 30초마다 | 기본 웨이브 (8절). 양 팀 동시에 같은 구성 |
| 2:00, 4:00, 6:00, 8:00 | 보스 웨이브 (기본 웨이브 자리에) |
| 3:00, 6:00 | 증강 선택. **10초 정지**, 전원이 3장 중 1장을 고른다 (10절) |
| 4:30, 7:30 | 이벤트 시간대 시작 (11절). 30초 전에 예고 |
| 10:00 | 종료 |

원작처럼 화면 양쪽에 두 라인이 다 보인다. 상대 라인에 내가 보낸 유닛이 걸어가는 것과, 내 라인에 상대가 보낸 유닛이 오는 것을 동시에 본다. **상대가 보낸 유닛은 출발 순간 보인다.** 오는 걸 보고 타워를 지어 대비하는 것이 원작의 핵심 재미이며 그대로 가져온다. 다만 유닛이 걸어오는 시간(라인 16칸, 늑대 기준 8초)이 대비할 수 있는 전부다.

## 5. 승리

- 상대 기지 체력 0 → **즉시 승리**.
- 10분 종료 시 남은 기지 체력 → 팀 인컴 → 팀 골드 합 순으로 비교. 전부 같으면 무승부.

## 6. 타워 (프로토타입 9종)

전부 처음부터 지을 수 있다. 표기: **비용 / 공격 / 공속(초당) / 사거리(칸)**. 태그는 `계열 · 직업`. 타워는 체력이 없고 공격받지 않는다 (흑마법사 침묵 같은 방해 능력만 받는다).

| # | 이름 | 비/공/공속/사거리 | 태그 | 특징 |
|---|---|---|---|---|
| 1 | 나무 궁수 | 6 / 4 / 1.0 / 3 | 숲·궁수 | 대공 가능. 기본 타워 |
| 2 | 가시 덤불 | 6 / 3 / 1.2 / 1.5 | 숲·전사 | 맞은 유닛 감속 30% (1.5초) |
| 3 | 숲의 드루이드 | 10 / 0 / - / 2 | 숲·마법사 | 사거리 안 아군 타워 공격력 +15% (중첩 불가) |
| 4 | 화염 창탑 | 7 / 5 / 1.0 / 2 | 불·전사 | 화상 (3초간 초당 2) |
| 5 | 불꽃 술사 | 9 / 7 / 0.6 / 2 | 불·마법사 | 광역 (반경 1칸) |
| 6 | 불사조 | 14 / 9 / 0.9 / 3 | 불·궁수 | 대공 가능, 공중에 피해 2배 |
| 7 | 태엽 포탑 | 8 / 12 / 0.4 / 4 | 기계·궁수 | 긴 사거리, 대공 불가 |
| 8 | 강철 대포 | 15 / 25 / 0.3 / 3 | 기계·전사 | 거인 계열에 피해 2배, 대공 불가 |
| 9 | 수리 드론 | 8 / 0 / - / 2 | 기계·마법사 | 사거리 안 기계 타워 공속 +25% (중첩 불가) |

- **대공**: 공중 유닛은 "대공 가능" 타워만 때릴 수 있다. 대공이 없으면 공중은 그냥 지나간다.
- 강화(1회): 공격·공속 +50%, 비용은 원가.
- 타워는 사거리 안에서 **기지에 가장 가까운** 유닛을 먼저 쏜다.

## 7. 공격 유닛 (뽑기 풀 11종)

뽑기 1회 5골드. 등급 확률: **일반 60% / 희귀 30% / 영웅 10%**. 표기: **보내기 비용 / 체력 / 속도 / 누수 / 인컴**. 공격력은 없다. 태그는 `계열` (야수·공중·거인·암흑).

| 등급 | 이름 | 비/체/속/누수/인컴 | 계열 | 특징 |
|---|---|---|---|---|
| 일반 | 늑대 | 4 / 30 / 2.0 / 1 / +1 | 야수 | 빠르다 |
| 일반 | 고블린 | 4 / 45 / 1.2 / 1 / +2 | 야수 | 인컴 효율이 좋다 |
| 일반 | 박쥐 | 4 / 25 / 2.2 / 1 / +1 | 공중 | 대공 없는 상대를 뚫는다 |
| 일반 | 거북 | 5 / 100 / 0.7 / 1 / +1 | 거인 | 느리지만 단단, 타워 화력을 오래 붙잡는다 |
| 희귀 | 오우거 | 8 / 180 / 1.0 / 2 / +2 | 거인 | 단단한 본대 |
| 희귀 | 그리핀 | 8 / 110 / 1.6 / 2 / +2 | 공중 | 대공이 약하면 치명적 |
| 희귀 | 암살자 | 8 / 60 / 1.8 / 2 / +1 | 암흑 | 출발 후 3초 은신 (타워가 못 본다) |
| 희귀 | 어둠 사제 | 9 / 70 / 1.0 / 1 / +2 | 암흑 | 주변 아군 유닛 초당 3 회복 |
| 영웅 | 드래곤 | 14 / 320 / 1.3 / 3 / +4 | 공중 | 등장 시 사거리 2 안 타워 1.5초 침묵 |
| 영웅 | 거대 골렘 | 14 / 450 / 0.6 / 4 / +3 | 거인 | 감속 면역 |
| 영웅 | 흑마법사 | 15 / 150 / 1.0 / 2 / +3 | 암흑 | 3초마다 가장 가까운 타워 2초 침묵 |

**무리 시너지** (같은 팀이 5초 안에 연달아 보낸 유닛끼리):
- 같은 이름 3마리: 체력 +20%
- 같은 계열 3마리 이상: 야수 → 속도 +20%, 공중 → 체력 +15%, 거인 → 누수 +1, 암흑 → 은신 1초 추가

## 9. 시너지 (타워)

**계열 시너지**는 내 팀 라인의 타워 전체(팀원 합산)로 센다. **직업 시너지**는 같은 줄(앞·중·뒷줄) 안에서 센다.

| 계열 | 3개 | 5개 |
|---|---|---|
| 숲 | 타워 사거리 +0.5 | 30초마다 기지 체력 +1 |
| 불 | 타워 공격 +10% | 처치 시 주변 유닛에 5 피해 |
| 기계 | 기계 타워 강화 비용 -30% | 기계 타워 공속 +20% |

| 직업 | 같은 줄 2개 이상 |
|---|---|
| 전사 | 그 줄 전사 타워 공격 +20% |
| 궁수 | 그 줄 궁수 타워 사거리 +1 |
| 마법사 | 그 줄 마법사 타워 효과 +50% |

## 10. 증강 (3:00, 6:00 에 10초 정지, 3장 중 1장, 비공개)

| 갈래 | 이름 | 효과 |
|---|---|---|
| 자원 | 상인 | 뽑기 비용 5 → 3 |
| 자원 | 이자 | 수입 때마다 보유 골드의 10% 추가 (최대 +5) |
| 자원 | 용병단 | 보낼 때 인컴 +1 추가 |
| 자원 | 유산 | 즉시 골드 +25 |
| 강화 | 정예 | 타워 강화 효과 +50% → +80% |
| 강화 | 맹독 | 내가 보낸 유닛 체력 +25% |
| 강화 | 대공망 | 궁수 계열 타워 전원 대공 가능 |
| 강화 | 요새 | 기지 체력 +8 |
| 방해 | 저주 | 내가 보낸 유닛이 등장할 때 사거리 2 안 상대 타워 공속 -20% (3초) |
| 방해 | 부식 | 상대 라인에서 내가 보낸 유닛이 죽을 때 상대 처치 보상 없음 |
| 방해 | 침묵탄 | 5초 안에 연달아 보낸 무리의 첫 유닛이 등장 시 타워 1.5초 침묵 |
| 정보 | 정찰 | 상대 손패 2장이 보인다 |
| 정보 | 감청 | 상대 팀의 핑이 보인다 |
| 정보 | 회계 | 상대 플레이어들의 골드 잔액이 보인다 |

증강은 개인 소유. 10초 정지는 전원 동시라 누구도 시간을 잃지 않는다.

## 12. 히든 미션

경기 시작 시 각자 1장, 팀원도 모른다. 달성 즉시 공개되고 보상은 미션마다 다르다.

| 이름 | 조건 | 보상 |
|---|---|---|
| 대군 | 5초 안에 유닛 5개 이상 보내기 | 골드 +15 |
| 철벽 | 90초 동안 누수 0 | 기지 체력 +4 |
| 구두쇠 | 골드 50 이상 보유한 채 수입 받기 | 팀 인컴 +4 |
| 순혈 | 같은 계열 타워 5개 | 그 계열 타워 전원 즉시 강화 |
| 보스 사냥 | 보스를 라인 절반 전에 처치 | 상대 기지 -4 |
| 급습 | 영웅 등급 2마리를 5초 안에 보내기 | 다음 보내기 3회 비용 0 |
| 검약 | 타워 3개 이하로 4:00 넘기기 | 증강 1개 추가 선택 |
| 학살 | 30초 안에 내 라인에서 15마리 처치 | 골드 +10, 기지 +1 |

## 13. 해금 (여러 판에 걸쳐, 조건 비공개)

| 조건 | 보상 |
|---|---|
| 누수 0으로 승리 | 새 타워 1종 |
| 한 판에 영웅 등급 5마리 이상 보내기 | 새 공격 유닛 1종 |
| 핑 없이 2v2 승리 | 새 이모트 |
| 히든 미션 8종 전부 한 번씩 달성 | 새 증강 갈래 |

## 14. 팀 협동

- 같은 라인, 같은 기지 체력, 같은 타워 격자. 앞줄·대공·광역을 누가 맡을지 자연스럽게 갈린다.
- 인컴은 팀 공유, 골드와 손패는 개인. 보내는 사람이 올린 인컴을 팀이 나눠 받는다.
- 실시간이라 역할이 저절로 생긴다. 한 명이 상대 라인을 보며 보내기에 집중하고, 한 명이 내 라인을 보며 타워를 짓는 식.
- 송금 자유, 핑 4종, 채팅 없음.

## 15. 개인전 (1v1)

같은 룰. 슬롯 12, 기지 30, 기본 웨이브 ×1. 핑과 송금 없음. 혼자서 양쪽 화면을 다 봐야 하므로 손이 바쁘다. 이게 1v1의 재미이자 난이도다.

## 16. 프로토타입 계획

1. **1단계 — 싸우는 화면** (진행 중): 라인 하나, 타워는 공격만, 유닛은 걷기만. 30초마다 기본 웨이브, 버튼으로 "상대가 보냄"을 흉내. 빈 슬롯을 눌러 타워를 실시간으로 짓는다. 골드 없음.
2. **2단계 — 루프**: 두 라인, 골드·인컴·뽑기·손패·보내기, 10분 타이머, 기지 체력, 승패. 1v1 vs AI.
3. **3단계 — 재미 요소**: 증강(10초 정지), 이벤트 시간대, 미션, 시너지, 무리 시너지. 밸런스 시뮬레이션 재가동.
4. **4단계 — 2v2/3v3 온라인** (락스텝 네트워크).

## 17. 첫 플레이테스트에서 답해야 할 질문

1. 오는 걸 보고 짓는 시간(8~20초)이 "대비하는 재미"를 주는가, 아니면 너무 짧아 운처럼 느껴지는가?
2. 방어와 보내기를 동시에 하는 게 정신없이 재밌는가, 그냥 정신없는가? (1v1에서 특히)
3. 손패에 카드를 쥐고 타이밍을 고르는가, 뽑히는 대로 보내는가?
4. 기본 웨이브가 너무 세서 상대가 보낸 게 의미 없어지진 않는가?
5. 공중 vs 대공이 가위바위보로 느껴지는가?
6. 증강 10초 정지가 흐름을 끊는가?

## 18. 구현 원칙

- **결정론 실시간 시뮬레이션**: 초당 20틱, 정수 좌표·체력·피해. 같은 (시드, 틱별 명령 목록)이면 어떤 기기에서든 같은 결과. 이것이 락스텝 멀티플레이와 리플레이의 기반이다.
- 시뮬레이션은 순수 C#, Unity 는 그리기와 입력만. 명령(짓기·강화·판매·뽑기·보내기·송금·핑)은 틱 번호가 붙은 데이터로만 시뮬에 들어간다.
- 멀티플레이는 **락스텝**: 각 클라이언트가 같은 시뮬을 돌리고 명령만 교환한다. 서버는 명령 중계와 시드 배포만 한다. 비동기 대전은 실시간 구조상 없다.
- 유닛·타워·증강·미션·웨이브 표는 데이터 파일로 둔다.
